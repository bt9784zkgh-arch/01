### 読み上げ・意味づけ（参考: WCAG 2.1 AA）
- 画面ごとに `section aria-label`、`#feedback` は role=status、おやすみは role=dialog・aria-modal、背景は inert → ○
- 選択肢の数字は aria-hidden、アイコン画像の alt は空。ボタン名は「いる」「かえられる」などことばだけ → ○
- 設定ボタンは aria-pressed で状態を伝える → ○
- 3D の `#stage3d` は aria-hidden → ○

## 直すべき点（担当名つき）

| 優先 | 担当 | 直すこと |
|---|---|---|
| 1 | **game-builder** | `[hidden]` が効くようにする。例: index.html の `<style>` に `[hidden]{display:none !important;}` を足す。おてほんの「つぎへ」、クリアの「つぎへ」、答えた後のほかの選択肢が、設計どおり見えなくなる |
| 2 | **game-builder** | ステップ3おてほんの箱（index.html `#screen-play[data-mode="model"] .choice--box { width:400px }`）の中で「かえられる／かえられない」がことばの途中で改行されないようにする。例: 幅を 480px 以上にするか、ラベルに `white-space:nowrap` をつけて文字を少し小さくする |
| 3 | **motion-3d** | タイトルの3D（温度計・ハート・しずく）が設定ボタン（`#settings`、1920基準で y≦164）に入らないようにする。例: `buildTitle` の中心 `appToWorld(1590, 320)` を下げる（y 380 前後）か、全体を小さくする。浮かぶ動き・回り込みの分（上へ約0.12〜0.3単位）も見こむ。SVG の `.title-ondokei` と温度計が2本並ぶ点は art-director と相談 |
| 4 | **art-director** | style.css の `rt` と `.choice .key-num` の文字色を、色つきボタン（lv1・lv3・can・cannot）の上では `--c-ink`（#33302C、7:1以上）にする。`.key-num` の文字を 28px 以上にする |
| 5（△） | game-builder／lesson-designer | ステップ2 Q3・Q4 で選んだことばを、いつも「大きい」に置くかどうか決める。同じことばがメーターの2か所に出ないようにする（例: すでに置いたことばは位置を動かす、またはまとめで「つよそう」と別に並べる） |
| 6（△） | art-director | face-3.svg の怒りマーク（赤い青すじ）をはずし、まゆを寄せる程度にする |
| 7（△） | game-builder | 「1{人\|り}ずつ」を「ひとりずつ」にする。まちがい2回目は `#feedback` を早めに消すか、ヒント絵とずらして出す |
