# ことばのウラ読み（作り直し版）

`index.html` をブラウザで開くと遊べます（1ファイルで完結。3D表示だけはネットから three.js を読みこみます。つながらないときは絵の吹き出し表示になります）。

## 前の版からの変更
- **問題を追加**：27問 → 35問。新しい場面「メッセージ・SNS」「お店・電話・近所の人」（各4問）と、3Dの場所「コンビニ」「美容院」を追加
- **①の選択肢を3つに**：「言葉どおりの意味」「ホンネ」に、もう1つまちがいを足して、当てずっぽうでは正解しにくくした。答えたあとも、どれを選んだか・正解がどれかが見えるようにした
- **ゲームの要素**：ポイント、マスターが続くとコンボボーナス、マスターのスタンプと紙ふぶき、マスター数で上がる称号（6段階）、場面ごとのベスト記録（★3つ）、やさしい効果音（ON/OFF可）。時間制限はなし
- 「ぜんぶの場面から」は、まだマスターしていない問題を優先して出す
- スマホでは「場面 → ① → ② → ③話してみよう」の順に並ぶように修正
- 前の版の記録（マスター・メモ）はそのまま引きつぐ。リセットでポイント・称号も消える

## 作り直すとき
問題は `src/questions.js`、画面とプログラムは `src/game.src.html`。直したら次で `index.html` を作り直す。

```
pip install fonttools brotli
python3 src/build.py <フォントのフォルダ>
```

フォントは Noto Sans JP / Noto Serif JP（源ノ角ゴシック・源ノ明朝と同じデザイン、SIL OFL 1.1）。使っている文字だけに絞って埋め込むので、文章を変えたら必ずビルドし直す。
