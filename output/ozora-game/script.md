# 大空 こころの たび 紹介

## 一言でいうと
気持ちに気づき、こまった時のよい行動を3ステップで学ぶゲーム。

## 要点
1. どんなゲームか: 特別支援学級向けワークブック「大空に翔け」（全96ページ、中学生向け）をもとにした、パソコンのブラウザで遊ぶ学習ゲーム。中心の力「こまった場面で、自分の気持ちに気づき、よい行動をえらぶ」にしぼっている。
   - 画像・キーワード: タイトル画面、青い線の紙の鳥、「たびの てちょう」（紙・スタンプ）
2. 3つのステップ: ステップ1「ことばの おくの 気持ち」（氷山の絵で、きつい言葉の下にある気持ちを2択でえらぶ・4問）、ステップ2「変えられる？ 変えられない？」（カードを手のはこ／くものはこに分ける・5問）、ステップ3「こまった とき、どうする？」（給食・テスト中の音・熱・あやしいメール・万引きのさそいで、よい行動を3択でえらぶ・5問）。
   - 画像・キーワード: 氷山、手のはこ・くものはこ、場面の絵＋3まいの行動カード
3. 安心して学べる工夫: 漢字にふりがな、「よむ」ボタンで読み上げ。失点・制限時間はなし。まちがえても「もういちど みてみよう」→ヒント→「いっしょに おして みよう」と進む。
   - 画像・キーワード: 「もういちど」札、黄色いヒント枠と鳥、手のカーソル
4. おと・うごきを選べる: 右上のボタンで、おと「あり／なし」、うごき「ふつう／すくなめ」を切りかえられる。点滅は1秒に3回までにおさえている。
   - 画像・キーワード: 右上の［おと］［うごき］［もどる］ボタン
5. かんたんに使える: index.html をダブルクリックするだけ。ネット不要（フォント・部品は同梱）。先生は game.js の先頭の LESSON を書きかえて、問題を変えられる。
   - 画像・キーワード: フォルダとindex.html、game.js の LESSON

## ナレーション原稿（30〜45秒）
「大空 こころの たび」は、特別支援学級の中学生向けの学習ゲームです。
もとは、ワークブック「大空に翔け」。
学ぶのは3つのステップです。
ひとつめは、ことばの おくに かくれた 気持ちに 気づくこと。
ふたつめは、変えられる ことと 変えられない ことを 分けること。
みっつめは、こまった とき、大人に 相談するなど、よい 行動を えらぶこと。
漢字には ふりがな。問題は 読み上げも できます。
点が へることも、時間の 制限も ありません。
まちがえても、ヒントが 出て、さいごは いっしょに 確かめます。
おとや うごきは、ボタンひとつで 減らせます。
使い方は、index.html を ダブルクリックするだけ。ネットは いりません。

## 対象読者・トーン
学校の先生・保護者向け／やさしく、安心感のある語り口
